实现：application/moduleRegistry.js集中页面懒加载、菜单图标、标题、设置说明、缓存与安全属性；App按元数据动态渲染，路由白名单和菜单/标题/设置范围同源。application/appNavigation.js独立管理导航状态、返回栈与滚动，Settings Store保留薄兼容接口。application/ordinaryModules.js为应用组合根，moduleLifecycle.js管理初始化/前台恢复/flush/清理；原生监听支持异步注册后卸载的竞态清理，控制器清理全部相关订阅与计时器。业务聚合仍在应用层显式组合，不隐藏必要跨模块协作。

验收：npm run check返回0；Node274/274，组件134/134（16文件），类型和构建通过，lint0错误/55警告。新增6项模块/lifecycle测试，及1项实际App动态渲染/KeepAlive测试。合成普通模块只增加描述与生命周期注册，即可进入、显示元数据、打开设置、返回并恢复滚动，无需App/控制器新增业务分支；生命周期只初始化/订阅一次，卸载清理一次，迟到的native listener也被移除。实际App会话内保留聊天编辑状态、锁定时isVisible=false、会话失效后卸载敏感缓存并清除旧草稿。
