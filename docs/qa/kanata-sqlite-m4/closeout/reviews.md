# M4 收尾复核记录

两轮分别按安全与数据路径、产品与设备验收进行。表中区分已测切片和仍缺验证。两轮都未达到合同的全范围完成标准。

## 第一轮 数据边界、事务、权限

| 范围 | 反例和结果 |
| --- | --- |
| A 世界与群聊 | 对照世界创建/归档和群聊 CAS。使用 v3 群聊实测。新增静态设置有名称、规则、时区和默认模式的 CAS 验证。静态复制及完整跨生命周期矩阵待接。 |
| B 卡片与实例 | 候选卡库版本检查保留。实例加入/同步和原生文件选择的挂起/恢复路径尚无候选端到端证据。 |
| C 世界书 | 已有角色 scope 和排序复测。分页并发变更、完整字段与连续性未验。 |
| D 记忆 | 旧普通聊天在预算拒绝前组装 1,000 个引用的反例已复现。流式分页编码消除完整引用数组，且对宽尾部继续授权。分享撤回使用单事务软删并保留边，后代和旧角色的正文读取拒绝。自定义合并保留两条精确引用。不同冲突组的跨组批量整理、独立宽撤权与异常关系矩阵未完成。 |
| E 事件 | 两档宽确认在主机中断后完整回滚，重试只应用冻结集合。撤销审计读取独立快照，修改源 Effects 不改变历史。旧全量修正/审计兼容调用与广度来源证明暂存仍需处理。 |
| F 自治与生活 | 候选授权修改会使 owner/lease 失效。contact/social 和全局绑定真实消费者缺接线，仍需覆盖解绑、归档及后台竞争。 |
| G 历史整理 | 预览与确认签名覆盖当前 scope/revision/范围，写失败保留原状态。常规来源和回复组件保留，归档后依旧可按 ID 引用。legacy 的非规范化扩展引用扫描等价未完整证明。 |

普通聊天已去掉记忆来源 DTO。事件、消息及记忆中大量**不同的生活授权标签**仍可能进入 provenance 集合，最终回复也沿用现有标签数组。需要独立宽样本及全链路界限，不能以零 `sourceRefs` 数组推定 G4 全过。

## 第二轮 产品流程、平台、证据

| 范围 | 已核对与未覆盖 |
| --- | --- |
| A | 候选空白世界与 GROUP-01～05 已有 v3 证据。静态复制需按 legacy 仅映射静态角色、会话结构、世界书和初始关系。静态设置有 Android SQLCipher 回读。 |
| B | 已有角色卡导入、发布与版本界面。实例生命周期和 PNG/JSON 原格式的候选原生往返未测全。 |
