### 拖动、保存与撤销

- 不再设置单独的整理模式或整理模式的“取消／完成”按钮。手机长按右上角六点约 350ms 激活拖动，电脑鼠标按住手柄并移动即可拖动。
- 长按等待期间，移动超过 8 CSS px、松手或收到 pointercancel 时取消激活；提前滑动按页面滚动处理。只有手柄可启动拖动，其他区域保持正常滚动与业务操作。
- 激活后卡片轻微抬起并增加阴影，原位置保留占位，相邻卡片平滑让位；支持时提供一次轻震动，不支持时不阻断操作。
- 靠近实际滚动容器上下边缘时自动滚动；结束、取消或页面停用时停止滚动、释放指针捕获并清理计时器和监听器。遵循系统减少动画设置。
- 拖动期间只维护临时 ID 顺序，暂时禁止分类切换、搜索、新建及卡片业务操作。松手且顺序变化时自动保存，未改变顺序则不写入。
- 保存成功后显示“顺序已更新 · 撤销”，保留 5 秒撤销入口；撤销恢复最近一次成功排序前的顺序并持久化。下一次成功排序替换撤销记录，离页或计划增删、分类变化后撤销入口失效。
- 保存期间禁止另一次排序或撤销，避免写入竞争。保存失败恢复到上次已保存顺序，提示“顺序未保存，请重新拖动”；撤销失败保持撤销前顺序并提示失败，不显示成功状态。
- 拖动中按 Android 返回键或 Escape，仅取消本次拖动并恢复原顺序；切页、锁屏、组件停用或 pointercancel 同样取消未完成拖动。已保存的顺序不因离页恢复。
- 搜索词非空时禁用手柄及其他排序入口，提示“清空搜索后可调整顺序”，避免只排序部分结果；当前分类不足两项或数据未加载完成时禁用排序。
- “更多”菜单提供上移／下移作为非拖动替代操作，适用相同保存与撤销规则；按钮支持键盘，首尾禁用不可用方向，手柄提供可读名称和操作提示。
