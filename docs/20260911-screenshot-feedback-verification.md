# 截图反馈修正验收

## 来源与修改

依据用户本轮提供的三张内嵌截图，文件名已记录在 source-notes.md。

- 体重图表：90 天/全部或超过 12 个数据点时去掉圆点、点上数值，只保留趋势线及日期轴；单个数据点仍显示以避免空白。
- 历史记录：修复历史列表误用图表日期过滤，列表始终显示全部记录，每页 10 条；显示总数与翻页栏，切换图表不改变当前历史页。此前是筛选隐藏，没有执行记录删除。
- 紧凑布局：日期分组间距缩小，记录卡片内边距和字号压缩，编辑/删除并排，操作触摸区域仍至少 44 px。
- 心情：删除日历“自动”文字以及列表、当天详情的自动说明；保留原记录、图标和补写能力。
- 默认优先级：超赞 50、开心 40、一般 30、低落 20、极差 10。旧五项全部为 0 时一次性迁移；已有不同数值保持，迁移后主动清零不再重置。
