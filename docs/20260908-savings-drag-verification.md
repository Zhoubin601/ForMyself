# 省钱计划拖动布局实施与验收

日期：2026-09-08。本文记录当日实现与本地验证结果。2026-09-09 已按用户要求改用模拟器并完成虚构数据交互回归，后续结果及备份文件缺失情况见 [模拟器验收记录](20260909-savings-emulator-verification.md)。

## 已实现

- 固定“省钱计划”标题与粉色存钱罐图形，标题下显示 AI 鼓励语；无配置或无可用缓存时提供固定缺省句。
- 紧凑累计金额摘要、连续单列计划卡片、已存金额与进度条、独立更多菜单；取消看板自定义入口并兼容旧备份。
- 右上角 44×44 CSS px 六点手柄，触摸长按约 350ms 激活；提前滑动仍滚动页面。鼠标按住移动直接拖动。
- 占位与移动动画、边缘自动滚动、返回／锁屏／页面停用取消；松手保存，成功后提供 5 秒撤销入口。更多菜单可上移／下移，搜索时禁用排序。
- 以原数组持久化分类内顺序，不更改金额或业务状态；校验成员、串行写入并防止业务更新被排序覆盖。
