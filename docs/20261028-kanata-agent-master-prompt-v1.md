- 沿用 Vue3、Pinia、Vite、Capacitor、DeepSeek 和现有模块/受保护会话/主密码/加密恢复/备份架构。新业务放 features，跨业务编排放 application，平台能力放 platform；模块页面/生命周期/备份/保护能力各自接入，不允许伪 DI 或新常驻 Python 服务。
