# ForMyself 每日待办与桌面组件 v8

本次发布为 Debug 签名的预发布测试版，沿用仓库现有发布方式。应用内版本为 1.0；发布标签为 `v2026.10.03-daily-todo-v8`，对应源码提交 `b2d4fdf05d998959782ee18d3a82a9486cbfb9b8`。

## 更新内容

- 独立每日待办模块，支持单次、每天、每周指定星期及每隔 N 天重复，包含完成、撤销和可选提醒。
- 支持“仅本次”和“本次及以后”编辑；版本拆分保留历史完成键和任务版本关系。
- 完整备份升级为 v10，兼容 v1～v9，增加待办单项导出和恢复。
- Android 桌面组件支持调整尺寸、上下滚动和直接勾选；采用深灰背景、薄荷青进度环、圆形勾选框及随尺寸变化的紧凑行距。
- 新建／编辑表单采用紧凑分组排版，进一步调整日期内边距和任务行间距。

## 验证与已知限制

- 项目检查通过：249 项 Node 测试、48 项组件测试、类型检查和 Vite 构建；lint 无错误，有 56 项已有警告。
- Android Debug、androidTest 构建通过，APK 完整性和签名校验通过。
- 隔离 API 30、31、37 模拟器完成尺寸调整、长标题、大字体、30 项滚动、空态、桌面完成／撤销及滚动位置验证；API 37 完成多实例计数一致性检查。
