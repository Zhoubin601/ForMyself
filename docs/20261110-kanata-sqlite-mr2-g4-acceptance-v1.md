## 已完成

- 候选聊天窗口、发送重试与引用定位使用轻量 transcript。回复权限使用已规范化的来源，正文按同世界、会话、角色和 revision 条件进入候选 prompt。读取上一位发言者与 CAS 使用纯消息状态投影。
- Memory.readPrompt 和事件上下文只返回授权后的正文、顺序和精确引用。Runtime 保留受预算限制的消息、记忆和事件根描述，使用当前角色最多七条直接模块授权。回复事务重新验证根和权限后，在 SQLite 内存工作表处理标签排序、原 JSON 去重与接收者标签，再原子写入规范化关系和旧兼容顺序提示。
- HistoryArchive 在 SQL 内识别原有规范化关系及 JSON 扩展内的嵌套精确引用。主机以 legacy 规划器对照 1,000 和 10,000 档，两档归档 ID 集合一致，SQL 页最多 50 行。真实 Android 历史页面回归验证了未知字段中的精确引用保护。
- 自治 claim/finish 用 50 行来源页检查已存任务，结果引用精确匹配任务、世界和消息 revision。任务事务保持租约、幂等键和回执。

## BLOCKED 条件

- 事件创建、提交、旧兼容预览/撤销/修正与 eventFromRow 仍可能物化完整关系。消息兼容 DTO 和 loadTask 仍能聚合标签或来源。

- 生产 canonical 保持 legacy。普通 APK SQLite 激活位 false，Schema 001–004 的 checksum 与冻结值一致。真实模型 API 调用为 0。
