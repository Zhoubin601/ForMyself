## 2026-09-05 长期维护重构与安全存储迁移

实施结果：

1. 将 `App.vue` 收敛为应用壳，生命周期、解锁后加载、深链、通知和桌面组件刷新集中到 `useAppController`。
2. 将原单文件设置页拆为 11 个职责明确的界面片段与 8 个 composable；保留原设置入口、数据格式和页面行为。
3. 新建统一 Preferences 适配层与存储键清单，写入串行化；Android API Key 延迟写入可由应用挂起流程显式冲刷。
4. 首页桌面组件改读版本化展示快照，Android Provider 不再耦合心情、体重和省钱 Store 的内部结构；日程快照同步增加版本号。
5. 主密码持久化改为 PBKDF2 验证记录，原始密码仅在解锁会话内使用；Android 生物快捷解锁通过 Keystore 保护的安全凭据恢复会话密码。
6. 旧明文主密码只在旧用户首次解锁期间暂存，密码库与聊天加载成功后才删除；API Key 成功写入独立安全凭据后才清理旧设置字段。
7. 改密采用“受保护数据重加密 -> 提交验证记录与生物凭据”的事务流程，失败时反向回滚；生物认证可以继续授权修改主密码。
8. 聊天、心情、日程的视图、Store 和领域服务分别归入 `features/chat`、`features/mood`、`features/schedule`。
9. 新增 ESLint、渐进 JavaScript 类型检查、Vitest 组件测试和 GitHub Actions Web/Android 两类任务；移除错误的 Linux 平台绑定直接依赖。

- Vite 生产构建、`npx cap sync android`、Android `assembleDebug` 通过。

## 2026-07-24 Android 2×2 桌面信息卡
