## 发现并修复的问题

Debug 构建默认启用 Capacitor 原生桥详细日志，会把插件调用参数与文件返回值写入 `logcat`。调用安全存储时可能暴露主密码或 API Key，读取加密文件时也会产生不必要的大段日志。

已在 `capacitor.config.json` 设置 `loggingBehavior: "none"`。重新同步和覆盖安装后，主密码输入、指纹解锁与页面加载期间的敏感桥日志计数为 0，崩溃计数为 0。
