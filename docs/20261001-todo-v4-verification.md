## 实现

- 默认目标3×3，允许双向缩放，最小可调整参数120×120dp。API31+读取桌面提供的尺寸列表；旧版读取尺寸选项。同一布局按实际宽高220dp阈值切换头部与8/12dp内边距，保留列表稳定ID。
- API31+使用静态绿色填充及左侧固定支点scaleX；API30使用预生成共享帧。一个16ms调度器跳过过期帧，分组提交背景局部更新。业务刷新读取一次快照并更新列表/计数，动画不读取待办或重建列表。
- 动画以首个绘制调度时刻开始400ms计时，使用匀速推进/回退；新变化衔接最后提交比例，结束保存精确值。尺寸、跨天及系统关闭动画时直接更新。
- 表单按内容取高度，上限为可见区域88%；安排与补充分组，名称独立，备注/结束日期按需展开。原生可见区域及visualViewport共同处理键盘，错误出现时滚动到可见位置。原有版本拆分、历史保护和备份格式保持。
